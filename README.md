# Weather Tracker

Hi guys! This is a weather tracker which allows you to trackm your weather. If you are badly addicted to coding, then weather tracker suits you the best!
Because we find the weather here by running the code, not just in the boring way which non-coders do!

## How to run?
---
1. Clone my repository or download as a zip.
2. Run the main py by typing "python main.py" in the terminal.
3. Enter your city and **Boom!**, you will get the details in the terminal itself
